# Synthetic fixtures

`legacy-nine-year-oracle.json` contains outputs from the earlier AI-assisted accounting diagnostic, frozen before this event engine was implemented. All figures are synthetic units. They are not balances of identifiable people, institutions or the US economy. Migration shares and the repayment schedule are modeling assumptions.

No third-party dataset or private manuscript is redistributed here. Public readers can reproduce the new results from the code and documented assumptions without obtaining the private input paper. Changes to this oracle require explicit justification and must not merely make a failing comparison pass.
